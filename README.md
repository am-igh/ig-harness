# IG Harness

The ICT4Peace Foundation's local control center: deadlines, tasks, emails needing a reply, projects, hours, finance and International Geneva events, in one place on the Mac.

**Status:** Phase 1 (skeleton and Today tab) starting October 2026. v1 runs locally for one user.

**Privacy by design:** local model by default; a single model gateway decides what may leave the machine, based on four sensitivity tiers; external calls are redacted, logged and capped; email is drafted, never sent.

See `CLAUDE.md` for the full project brief and rules, and `docs/design/` for the approved interface mockup.
